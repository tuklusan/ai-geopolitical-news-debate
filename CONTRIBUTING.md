# Contributions are not accepted

This repository is the companion code for a published article. It is
read-only for everyone except its author.

- **Issues are disabled.** Please do not look for a way to report defects here.
- **Pull requests are not accepted** and will be closed without review.
- Discussions, the wiki, and projects are disabled.

This is not a judgement on anyone's patch. The repository exists so readers of
the article can see and run exactly the code it describes; accepting outside
changes would break that correspondence.

## What you can do instead

The licence permits non-commercial use, modification, and redistribution of
your own copy. If you want to change something, take the code and make it
yours, keeping the attribution the licence requires:

> Based on original work by Supratim Sanyal of SANYALnet Labs.

If you believe you have found a genuine security problem, contact the author
through the blog rather than opening anything here.
